
.. _err_code:

5. 错误码 
**************************************

* 对应的类名: ``ErrorCode.java``
* 属性引用: **ErrorCode#** ``xxx``

=============================================== ========================================= ==================================================================================== 
                错误定义                                           错误码                                             错误描述
=============================================== ========================================= ====================================================================================
 ERR_UNKNOWN                                       -1                                        未知错误
 ERR_NONE                                          0                                         没有错误
=============================================== ========================================= ====================================================================================
