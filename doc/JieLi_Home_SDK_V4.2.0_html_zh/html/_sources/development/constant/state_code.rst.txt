
.. _state_code: 

3. 状态码
***********************************************

* 对应类名: ``StateCode.java``
* 属性引用: **StateCode#** ``xxx``


.. _connection_code:

3.1 连接状态
==============================================

================================================= ====================================== =========================================
                引用声明                                         码值                                    说明
================================================= ====================================== =========================================
  CONNECTION_DISCONNECT                                          0                            设备未连接
  CONNECTION_OK                                                  1                            设备连接成功/设备已连接
  CONNECTION_FAILED                                              2                            设备连接失败
  CONNECTION_CONNECTING                                          3                            正在连接中
  CONNECTION_CONNECTED                                           4                         | 设备已连接
                                                                                           | ``已弃用``
================================================= ====================================== =========================================
