SDK说明

1. SDK简介

杰理之家SDK基于杰理RCSP协议实现, 主要支持音箱SDK和耳机SDK, 也支持直播声卡等系列产品。SDK提供了丰富的功能接口:

  • 音乐控制功能 — 手机音乐播放控制、设备音乐播放控制、ID3音乐信息显示

  • 设备设置功能 — 音量设置、状态查询、重启设备等

  • 文件浏览功能 — 查看SD卡、U盘等音乐文件列表

  • 闹钟管理功能 — 闹钟的增删改查, 闹钟铃声设置

  • FM控制功能 — FM收音功能、FM发射功能

  • 灯光控制功能 — 灯光闪烁, 频率, 颜色(RGB), 模式等控制, 实现酷炫效果

  • EQ调节功能 — 均衡器音效调节, 轻易打造卓越音质

  • 音效调节功能 — 混响、高低音设置

  • 按键设置功能 — 耳机按键功能设置, 丰富耳机功能

  • 查找设备功能 — 查找设备或查找手机

  • ANC设置功能 — 噪声处理模式设置, 支持正常模式、主动降噪模式、通透模式等

  • 自定义命令 — 支持客户拓展功能

2. SDK架构

Important

1. RCSP处理层 依赖 RCSP协议 实现, RCSP协议 依赖 蓝牙代理层 实现
2. SDK默认实现了 蓝牙代理层 的功能，也支持客户外部实现。
