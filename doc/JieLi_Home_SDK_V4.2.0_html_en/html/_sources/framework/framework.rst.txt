SDK Description
********************************************

1. SDK Introduction
============================================

|   The JieLi Home SDK is implemented based on the JieLi RCSP protocol and primarily supports speaker and headphone SDKs, as well as live streaming sound cards and other related products. 
|   The SDK provides a rich set of functional interfaces:

       * Music Control Function  --- Mobile music playback control, device music playback control, ID3 music information display, etc.
       * Device Settings Function  --- Volume settings, status check, device restart, etc.
       * File Browsing Function  --- Browse files on storage devices such as USB drives and SD cards, play music files, delete files, etc.
       * Alarm Clock Management Function  --- Adding, deleting, modifying, and querying alarms; setting alarm ringtones, etc.
       * FM Control Function  --- FM radio function, FM transmitter function, etc.
       * Lighting Control Function  --- Control the light's blinking, frequency, color (RGB), mode, etc., to achieve cool effects.
       * Equalizer Adjustment Function  --- Equalizer sound effects adjustment, easily create superior sound quality.
       * Sound Effect Adjustment Function  --- Reverb, treble and bass settings, etc.
       * Button Settings Function  --- Headphone button function settings to enrich headphone functionality.
       * Find Device Function  --- Find device or find phone
       * ANC Settings Function  --- Noise processing mode settings, supporting normal mode, active noise cancellation mode, transparency mode, etc.
       * Custom Command  --- Supports customer expansion functions

.. important::
    | 1. The ``RCSP Protocol Layer`` depends on the ``RCSP Protocol``, ``RCSP Protocol`` relies on the ``Bluetooth Proxy Layer`` for implementation. 
    | 2. The SDK implements the ``Bluetooth Proxy Layer`` functionality by default, and also supports external implementations by clients.
