Bluetooth Proxy Module
*******************************************************


.. note::
   | 1. This module is only used for ``built-in Bluetooth proxy implementation``. 
   | 2. ``JL_BluetoothManager`` is for Bluetooth interface management. :ref:`bt_manager_api` 
   | 3. ``BluetoothOperationImpl`` is the specific implementation of the Bluetooth function. :ref:`bt_op_api` 


.. _scan_device:

Scan Bluetooth devices
=======================================================

Start scanning device
-------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.
    //Bluetooth event listener
    final BTEventCallback btEventCallback = new BTEventCallback() {
        @Override
        public void onDiscoveryStatus(boolean bBle, boolean bStart) {
            //Callback to detect device status
        }

        @Override
        public void onDiscovery(BluetoothDevice device, BleScanMessage bleScanMessage) {
            //Callback to discovered Devices
        }
    };
    //Add Bluetooth event listener
    btManager.addEventListener(btEventCallback);
    int scanType = BluetoothConstant.SCAN_TYPE_BLE; //Scanning device type --- BLE device
    // BluetoothConstant.SCAN_TYPE_CLASSIC --- Classic Bluetooth devices
    int timeout = 30 * 1000; //Search timed out --- 30 seconds
    //Perform scanning device
    btManager.scan(scanType, timeout);
    //Remove Bluetooth event listener
    //        btManager.removeEventListener(btEventCallback);


.. important::
   1. To scan for Bluetooth devices, you need to ensure that ``Bluetooth`` is enabled.
   2. Scanning Bluetooth devices requires ensuring ``permissions``. 

      #. Android 6.0+, ``Bluetooth permissions`` and ``location permissions``
      #. Android 12.0+, ``Bluetooth search permission`` 
   3. Scanning for Bluetooth devices requires ensuring that ``location services`` are enabled.
   4. Scan Bluetooth device configuration, refer to :ref:`bluetooth_option` 




Stop scanning devices
-------------------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.
    //Execute stop scanning device
    btManager.stopScan();


.. _connect_device:

Connecting devices
=====================================================================


.. important::
   1. To connect the device, please ensure that ``Bluetooth`` is enabled.
   2. Connecting to the device requires ensuring that ``permissions`` have been granted.

      * Android 6.0+, ``Bluetooth permissions`` and ``location permissions``
      * Android 12.0+, ``Bluetooth connection permission``
   3. Connecting to devices requires that operations be performed linearly, not concurrently.
   4. Connecting devices refers to connecting communication protocols (BLE/SPP), excluding classic Bluetooth services.
   


Communication methods for connecting devices
----------------------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.

        @Override
        public void onConnection(BluetoothDevice device, int status) {
            //Callback Bluetooth connection status
        }
    };
    //Add Bluetooth event listener
    btManager.addEventListener(btEventCallback);
    //Execution connection device
    btManager.connect(device);
    //Execute disconnect device
    //        btManager.disconnect(device);
    //Remove Bluetooth event listener
    //        btManager.removeEventListener(btEventCallback);

Data Read and Write
==========================================================================

Receive Data
--------------------------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.
    //Get Bluetooth function implementation object
    final IBluetoothOperation btOp = btManager.getBluetoothOperation();
    //Bluetooth event callback
    final BluetoothCallbackImpl bluetoothCallback = new BluetoothCallbackImpl() {
        @Override
        public void onBleDataNotification(BluetoothDevice device, UUID serviceUuid, UUID characteristicsUuid, byte[] data) {
            //BLE data received via callback
        }

        @Override
        public void onSppDataNotification(BluetoothDevice device, byte[] data) {
            //SPP data received via callback
        }
    };
    //Register Bluetooth event callback
    btOp.registerBluetoothCallback(bluetoothCallback);
    //Cancel Bluetooth event callback
    //        btOp.unregisterBluetoothCallback(bluetoothCallback);


.. note:: 
    1. The ``Gatt Over BR/EDR`` data reception operation is the same as the ``BLE`` data reception operation.

Historical Record Management
==================================================================================

Get history list
----------------------------------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.
    //Get history list
    final List<HistoryBluetoothDevice> historyDevices = btManager.getHistoryBluetoothDeviceList();



Back to History
------------------------------------------------------------------------------------


.. code-block:: java

    //Get Bluetooth operation object
    final JL_BluetoothManager btManager = RCSPController.getInstance().getBluetoothManager();
    if (null == btManager) return; //Custom Bluetooth implementation, btManager is empty.
    HistoryBluetoothDevice history = null; //History records cannot be empty.
    int timeout = 45 * 1000; //Connection timeout
    //Execute back connection history operation
    btManager.reconnectHistoryBluetoothDevice(history, timeout, new OnReconnectHistoryRecordListener() {
        @Override
        public void onSuccess(HistoryBluetoothDevice history) {
            //Callback to historical records successful
        }

        @Override
        public void onFailed(HistoryBluetoothDevice history, BaseError error) {
            //Callback to connect to history failed
            //history --- Historical record
            //error   --- error message
         }
    });

.. note::
   Historical record, :ref:`history_device`
