.. _sound_card_func:

Sound Card Function
***********************************************

.. important::
    Sound card function needs to negotiate function index with firmware engineer


Get Sound Card Function Status
=====================================================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC``       -- Public attributes
| **mask :**   ``0x01 << AttrAndFunCode.SYS_INFO_ATTR_SOUND_CARD``  -- Sound card function

Command construction

.. code-block:: java

    CommandBase getSoundCardStatusInfoCmd = CommandBuilder.buildGetSoundCardStatusInfo();


Code example reference :ref:`get_sys_info`

2. RCSPController Way

.. code-block:: java

    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Register Bluetooth RCSP event listener
    controller.addBTRcspEventCallback(new BTRcspEventCallback() {
        @Override
        public void onSoundCardStatusChange(BluetoothDevice device, long mask, byte[] values) {
            //Callback sound card status here
        }
    });
    //Execute get sound card status information function and wait for result callback
    controller.getSoundCardStatusInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
            //Result will be in BTRcspEventCallback#onSoundCardStatusChange callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });


Get Sound Card Effect Parameters
=========================================================

1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC``       -- Public attributes
| **mask :**     -- Sound card effect
    * ``0x01 << AttrAndFunCode.SYS_INFO_ATTR_SOUND_CARD_EQ_FREQ``
    * ``0x01 << AttrAndFunCode.SYS_INFO_ATTR_SOUND_CARD_EQ_GAIN``

Command construction

.. code-block:: java

    CommandBase getSoundCardEqInfoCmd = CommandBuilder.buildGetSoundCardEqInfo();


Code example reference :ref:`get_sys_info`

    //Get RCSPController object

    //Register Bluetooth RCSP event listener
    controller.addBTRcspEventCallback(new BTRcspEventCallback() {
        @Override
        public void onSoundCardEqChange(BluetoothDevice device, EqInfo eqInfo) {
            //Callback sound card effect information here
        }

    //Execute get sound card effect information function and wait for result callback
    controller.getSoundCardEqInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
            //Result will be in BTRcspEventCallback#onSoundCardEqChange callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });


.. note::
   1. :ref:`eq_info` 




Set Sound Card Function
==================================================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC``   -- Public attributes
| **type :**  ``AttrAndFunCode.SYS_INFO_ATTR_SOUND_CARD``       -- Sound card function
| **value :**  index(1Byte)+value(2Bytes)



Command construction

.. code-block:: java

    int index = 0;  //Function index
    int value = 2;  //Function value
    CommandBase setSoundCardInfoCmd = CommandBuilder.buildSetSoundCardInfo((byte)index, value);


Code example reference :ref:`set_sys_info`

2. RCSPController Way 

.. code-block:: java

    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //index --- Index
    int index = 0;
    //value --- Value
    byte[] value = new byte[0];
    //Set sound card function and wait for result callback
    controller.setSoundCardFunction(controller.getUsingDevice(), index, value, new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });


Set Sound Card Effect
===================================================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC``         -- Public attributes
| **type :**  ``AttrAndFunCode.SYS_INFO_ATTR_SOUND_CARD_EQ_GAIN``     -- Sound card effect
| **value :**  len(1Byte)+payload(n Bytes)

Command construction

.. code-block:: java

    byte[] data = new byte[2];
    data[0] = 2;  //len
    data[1] = 1;  //payload
    CommandBase setSoundCardEqValueCmd = CommandBuilder.buildSetSoundCardEqValue(data);


Code example reference :ref:`set_sys_info`

    //Get RCSPController object

        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });

**Field Description**

===================== ===========================================================
  Field                 Description
===================== ===========================================================
 id                    Distinguish category
 title                 Title
 icon_url              Project icon link
 type                 | Sub-item control type:
                      | Currently supported:
                      | img_select(can set image),select,slider
 column               | Control column count,
                      | Invalid when type==slider
 row                  | Control row count,
                      | Need to combine with column and paging==true to be effective
 paging               | Control unique identification code, globally unique,
                      | When group is true, index is invalid
 max                  | Maximum value,
                      | Valid when type==slider
 group                | Whether group type,
                      | true then no index field, valid when type is select
 enable               | Valid for slider type,
                      | true:app can adjust, false:app cannot adjust
===================== ===========================================================
