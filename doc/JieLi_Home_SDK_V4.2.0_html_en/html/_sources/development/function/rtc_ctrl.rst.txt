.. _rtc_ctrl_func:

Clock Function
**************************


Synchronize Time
============================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_RTC``           -- Clock function
| **type :**  ``AttrAndFunCode.SYS_INFO_ATTR_RTC_TIME``              -- Identify update time
| **value :**  timestamp: year(2Bytes) + month(1Byte) + day(1Byte) + hour(1Byte) + minute(1Byte) + second(1Byte)

Command construction

.. code-block:: java

    CommandBase syncTimeCmd = CommandBuilder.buildSyncTimeCmd(Calendar.getInstance());


Code example reference :ref:`set_sys_info`

2. RCSPController Way

.. code-block:: java

    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Execute synchronize time function and wait for result callback
    controller.syncTime(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });


Read Alarm List
===========================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_RTC``  -- Clock function
| **mask :**   -- Clock parameters
|   
|    * AttrAndFunCode.SYS_INFO_ATTR_RTC_ALARM              -- Alarm list
|    * AttrAndFunCode.SYS_INFO_ATTR_RTC_ALARM_EXPAND_FLAG  -- Alarm expand parameters
|    * AttrAndFunCode.SYS_INFO_ATTR_RTC_ALARM_VER          -- Alarm version

Command construction

.. code-block:: java

    CommandBase getAlarmListCmd = CommandBuilder.buildGetAlarmCmd();


Code example reference :ref:`get_sys_info`

2. RCSPController Way

.. code-block:: java

    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Register Bluetooth RCSP event listener
    controller.addBTRcspEventCallback(new BTRcspEventCallback() {
        @Override
        public void onAlarmListChange(BluetoothDevice device, AlarmListInfo alarmListInfo) {
            //Callback alarm list information here
        }
    });
    //Execute get alarm list function and wait for result callback
    controller.readAlarmList(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
            //Result will be BTRcspEventCallback#onAlarmListChange callback
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    });

.. note::
   1. Alarm list information, :ref:`alarm_list_info`

.. _alarm_bean:

AlarmBean
-----------------------------------

Alarm information

.. code-block:: java

    public class AlarmBean {
        //Index
        private byte index;
        //Name
        private String name;
        //Hour
        private byte hour;
        //Minute
        private byte min;
        //Type
        private byte repeatMode;
        //Expand field
        private String reserved;
        //Is open
        private boolean open;
        //Bell type
        private byte bellType;//0: Default type  1: Device file type
        //Bell cluster
        private int bellCluster; //When bellType=0, here is bell index When bellType=1, here is file cluster number
        //Bell name
        private String bellName; //Valid when bellType=1
        //Device index where bell is located
        private byte devIndex;//Valid when bellType=1

        private int version;
    }
