.. _fm_ctrl_func:

FM Control Function
********************************************

.. important:: 
    1. Except :ref:`get_fm_tx_info` and :ref:`set_fm_tx_freq` , other interfaces require device to be in 【FM Mode】 to take effect, 
    2. Determine if device supports 【FM Mode】
    
    .. code-block:: java
      
        public boolean isSupportFMMode() {
            //Get RCSPController object
            RCSPController controller = RCSPController.getInstance();
            //Get current operation device
            BluetoothDevice usingDevice = controller.getUsingDevice();
            if (null == usingDevice) return false;
            DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
            if (null == deviceInfo) return false; //Device not initialized
            return deviceInfo.isFmEnable();
        }
   

    3. Determine if device is in 【FM Mode】
   
    .. code-block:: java

        public boolean isDeviceInFMMode() {
            //Get RCSPController object
            RCSPController controller = RCSPController.getInstance();
            //Get current operation device
            BluetoothDevice usingDevice = controller.getUsingDevice();
            if (null == usingDevice) return false;
            DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
            if (null == deviceInfo) return false; //Device not initialized
            return deviceInfo.getCurFunction() == AttrAndFunCode.SYS_INFO_FUNCTION_FM;
        }

    4. :ref:`get_device_mode` 


Get FM Status Information
========================================================


1. JL_BluetoothManager Way

| **function :**  ``AttrAndFunCode.SYS_INFO_FUNCTION_FM``         -- FM function
| **mask :**   ``0x01 << AttrAndFunCode.SYS_INFO_ATTR_FM_STATU``  -- Play status

Command construction

.. code-block:: java

    CommandBase getFmStatueCmd = CommandBuilder.buildGetFmStatueCmd();


Code example reference :ref:`get_sys_info`

2. RCSPController Way

.. code-block:: java

    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Add Bluetooth RCSP event listener
    controller.addBTRcspEventCallback(new BTRcspEventCallback() {

        @Override
        public void onFmStatusChange(BluetoothDevice device, FmStatusInfo fmStatusInfo) {
            //Callback FM status information here
        }
    });
    //Execute get FM status information function and wait for result callback
    controller.getFmInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Success callback
            //Result will be callback in BTRcspEventCallback#onFmStatusChange
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Failure callback
            //error - error information
        }
    }); 


.. note::
   1. :ref:`fm_status_info`
