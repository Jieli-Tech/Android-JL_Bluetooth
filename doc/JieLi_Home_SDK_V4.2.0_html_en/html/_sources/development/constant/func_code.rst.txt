4.1 Functional Mode
===================================================================

              Citation Declaration                               Value                                                              Explanation                                                                                        Functional Subset
================================================= ====================================== =============================================================================================================== =============================================================
  SYS_INFO_FUNCTION_PUBLIC                                       255(0xFF)                   Public mode. (Not a separate mode; sub-functions are available in all modes.)                                 :ref:`public_mode_sub_func_list` 
  SYS_INFO_FUNCTION_BT                                            0                          Bluetooth mode. (Basic mode)                                                                                  :ref:`bt_mode_sub_func_list` 
  SYS_INFO_FUNCTION_MUSIC                                         1                       |  Music Mode                                                                                                    :ref:`device_music_mode_sub_func_list` 
                                                                                          |  (Supports device music operations, such as music file browsing and music file playback)
  SYS_INFO_FUNCTION_RTC                                           2                       |  Clock mode. (Merged into [Bluetooth mode], no longer a separate mode)                                         :ref:`rtc_mode_sub_func_list` 
                                                                                          |  (Supports clock operations, such as time synchronization, alarm clock operation, stopwatch, etc.)
  SYS_INFO_FUNCTION_AUX                                           3                       |  External device mode                                                                                          :ref:`aux_mode_sub_func_list` 
                                                                                          |  (Supports operation of external devices, such as music pause and play)
  SYS_INFO_FUNCTION_FM                                            4                       |  FM receiver mode                                                                                              :ref:`fm_mode_sub_func_list` 
                                                                                          |  (Supports FM reception operations, such as searching for and playing radio stations.)
  SYS_INFO_FUNCTION_LIGHT                                         5                       |  Lighting modes                                                            
                                                                                          |  (Supports setting up lighting effects, such as light color and flashing effects)
  SYS_INFO_FUNCTION_FMTX                                          6                       |  FM transmission mode. (Merged into [Common Mode], no longer a separate mode)
                                                                                          |  (Supports FM transmission operations, such as setting the frequency.)
  SYS_INFO_FUNCTION_EQ                                            7                          EQ mode (merged into the [Common Mode], no longer a separate mode)
  SYS_INFO_FUNCTION_SPDIF                                         8                          Digital audio mode                                                                                             :ref:`spdif_mode_sub_func_list` 
  SYS_INFO_FUNCTION_PC_SLAVE                                      9                          PC slave mode                                                                                                  :ref:`pc_slave_mode_sub_func_list` 
 |
  SYS_INFO_FUNCTION_LOW_POWER                                    22(0x16)                    Low power mode
