JieLi Home SDK_Android_V2.9.0

Version Level: A
Release Date: 2021/08/11
SDK Version: V2.9.0
Release Notice
1. Add a snooze mode to the speaker SDK’s alarm clock:
Added parameter settings to the existing ringtone settings: Currently supports: alarm count, ringtone duration, alarm interval.
2. Added active noise cancellation (ANC) settings to the headphone SDK:
The firmware can be customized to support active noise cancellation settings for the headphones. Currently supported modes include: Noise Cancellation, Transparency, and Normal.
3. Fix Android 11 compatibility issues:
Android 11 does not support some interfaces, causing older SDKs to sometimes crash. The new SDK fixes this issue.
Applicable chip range: AC697N、AC696N、AC695N、AC692N, etc
Corresponding firmware SDK versio: Please use the latest firmware SDK
