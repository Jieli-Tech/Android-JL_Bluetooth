2.1.4 Why does my phone’s Bluetooth interface show that it’s connected, but the SDK returns that the device is not connected?

Problem Description: Why does my phone's Bluetooth interface show that it's connected, but the SDK returns that the device is not connected?
Test Environment: Firmware: AC693N_soundbox_SDK_Vxxx or AC696N_soundbox_SDK_Vxxx or JL700N_soundbox_SDK_Vxxx
SDK Version: jl_bluetooth_rcsp_Vxxx
Reproduction Steps: 1. xxxx 2. xxxx 3.xxxx
Reproduction Steps: NULL
Recurrence Probability: Must appear
Can the public version demo be reproduced? YES
Time period of problem occurrence: NULL
Answer:
The SDK determines device connectivity based on whether the communication service is connected. This communication service specifically refers to BLE and SPP, excluding classic Bluetooth service. Since the phone’s system Bluetooth interface connects to classic Bluetooth service, the SDK will not return a connection confirmation.

To determine the classic Bluetooth status of a device, use the following code:
BluetoothDevice device = BluetoothUtil.getRemoteDevice("classic Bluetooth address of the device");
if(null == device) return;
int state = RCSPController.getInstance().getBtOperation().isConnectedByProfile(device);
//state has the following values:
//        BluetoothProfile.STATE_DISCONNECTED  --- Disconnected
//        BluetoothProfile.STATE_CONNECTING    --- Connecting
//        BluetoothProfile.STATE_CONNECTED     --- Connected
//        BluetoothProfile.STATE_DISCONNECTING --- Disconnecting

      UUID.fromString("Your write characteristic UUID"),

RCSPController.getInstance().configure(option);
