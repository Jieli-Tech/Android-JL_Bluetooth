3. Volume Control Function

3.1. Get Current Device Volume

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attribute
mask : 0x01 << AttrAndFunCode.SYS_INFO_ATTR_VOLUME – Identify system volume

Command construction

//Construct get current device volume
CommandBase getVolumeCmd = CommandBuilder.buildGetVolumeCmd();

Code example reference Query device system information

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {
    @Override
    public void onVolumeChange(BluetoothDevice device, VolumeInfo volume) {
        //Device volume info will be callback here
    }
});
//Execute get current volume function and wait for result callback
controller.getCurrentVolume(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be in BTRcspEventCallback#onVolumeChange callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - Error info
    }
});

Note

  1. Volume info, VolumeInfo

3.1.1. VolumeInfo

Volume info

public class VolumeInfo {
    private int maxVol;  //Maximum volume
    private int volume; //Current volume
    private boolean supportVolumeSync=false; //Whether volume sync is supported
}

3.2. Adjust Device Volume

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attribute
type : AttrAndFunCode.SYS_INFO_ATTR_VOLUME – Identify system volume
value : volume (1Byte) – Volume

Command construction

//Construct set current device volume
int volume = 16; //Volume level, maximum volume level can be obtained in device info
CommandBase setVolumeCmd = CommandBuilder.buildSetVolumeCmd(volume);

Code example reference Configure device system properties

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {
    @Override
    public void onVolumeChange(BluetoothDevice device, VolumeInfo volume) {
        //Device volume info will be callback here
    }
});
VolumeInfo volume = null; //Volume info, cannot be null
//Execute adjust volume function and wait for result callback
controller.adjustVolume(controller.getUsingDevice(), volume, new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be in BTRcspEventCallback#onVolumeChange callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - Error info
    }
});

3.4. Set High and Low Tone

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attribute
type : AttrAndFunCode.SYS_INFO_ATTR_HIGH_AND_BASS – Identify high and low tone function
value : bass (4Bytes) + high(4Bytes) / Low tone value + High tone value

Command construction

int high = 16; //High tone value
int bass = 16; //Low tone value
CommandBase setHighAndBassCmd = CommandBuilder.buildSetHighAndBassCmd(high, bass);
