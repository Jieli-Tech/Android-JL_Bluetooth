20. Color Screen Charging Case Function

20.1. Monitor Color Screen Charging Case Events

//Step1. Create color screen charging case implementation class
ChargingCaseOpImpl chargingCaseOp = ChargingCaseOpImpl.instance(RCSPController.getInstance().getRcspOp());
//Step2. Add color screen charging case event listener
final OnChargingCaseListener listener = new OnChargingCaseListener() {

    @Override
    public void onInit(BluetoothDevice device, int state) {
        //Callback for initialization status
        //0 --- Success
        //Other values are error codes, refer to 【Error Codes】 section
    }

    @Override
    public void onChargingCaseInfoChange(BluetoothDevice device, @ChargingCaseInfo.Function int func, ChargingCaseInfo info) {
        //Callback for color screen case function changes
        switch (func) {
            case ChargingCaseInfo.FUNC_BRIGHTNESS: //Screen brightness
                    info.getBrightness();
                    break;
                case ChargingCaseInfo.FUNC_FLASHLIGHT: //Flashlight switch
                    info.isFlashlightOn();
                    break;
                case ChargingCaseInfo.FUNC_SCREEN_SAVERS: //Screen saver resource list
                    info.getScreenSavers();
                    break;
                case ChargingCaseInfo.FUNC_CURRENT_SCREEN_SAVER: //Current screen saver resource
                    info.getCurrentScreenSaver();
                    break;
                case ChargingCaseInfo.FUNC_CURRENT_BOOT_ANIM: //Current boot animation
                    info.getCurrentBootAnim();
                    break;
                case ChargingCaseInfo.FUNC_WALLPAPERS: //Wallpaper resource list
                    info.getWallpapers();
                    break;
                case ChargingCaseInfo.FUNC_CURRENT_WALLPAPER: //Current wallpaper resource
                    info.getCurrentWallpaper();
                    break;
            }
        }

        @Override
        public void onChargingCaseEvent(BluetoothDevice device, SettingFunction function) {
            //Callback for color screen case function events, also returned via onChargingCaseInfoChange interface, can be ignored
        }
    };
    chargingCaseOp.addOnChargingCaseListener(listener);
    //Step3. When no longer needed, remember to release the listener
    //chargingCaseOp.removeListener(listener);

Important

  1. Initializing the 【ChargingCaseOpImpl】 object triggers the initialization process;

  2. If initialization fails, troubleshoot according to 【Error Codes】; 5. Error Code

  3. If initialization succeeds, the 【ChargingCaseOpImpl】 object has the basic information object 【ChargingCaseInfo】;

  4. Users can query 【Screen Information】 and 【SDK Information】 in 【ChargingCaseInfo】;

  5. ChargingCaseInfo

  6. ScreenInfo

  7. SDKMessage

20.6. Screen Saver Control Function

20.6.1. Browse Screen Saver Resources

//Step1. Create color screen charging case implementation class
ChargingCaseOpImpl chargingCaseOp = ChargingCaseOpImpl.instance(RCSPController.getInstance().getRcspOp());
//Step2. Select storage to browse
final BluetoothDevice device = RCSPController.getInstance().getUsingDevice();
List<SDCardBean> onlineStorages = chargingCaseOp.getOnlineStorages(device); //Get online storage list
if (onlineStorages.isEmpty()) return; //No storage. Operation failed
SDCardBean target = null;
for (SDCardBean storage : onlineStorages) {
    //Prioritize finding Flash and Flash2
    if (storage.getIndex() == SDCardBean.INDEX_FLASH || storage.getIndex() == SDCardBean.INDEX_FLASH2) {
        target = storage;
        break;
    }
}
if (target == null) {
    target = onlineStorages.get(0);
}
//Step3. Call the interface to browse screen savers
//Get storage handler
int devHandler = target.getDevHandler();
chargingCaseOp.browseScreenSavers(device, devHandler, new OnRcspActionCallback<List<RegFile>>() {
    @Override
    public void onSuccess(BluetoothDevice device, List<RegFile> message) {
        //Callback for operation success
        //message --- resource list
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Callback for operation failure and error information
        //error.getSubCode() --- error code
        //error.getMessage() --- error description
    }
});

Note

  1. RegFile

  2. When the color screen case is initialized, it automatically synchronizes the resource list once. Subsequently, when 【creating screen saver resources】 or 【deleting screen saver resources】 operations occur, manual synchronization can be done.
