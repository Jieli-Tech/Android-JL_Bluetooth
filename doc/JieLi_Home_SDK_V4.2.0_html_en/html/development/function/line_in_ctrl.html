7. External Device Control Function

Important

  1. Interface requires device to be in 【External Device Mode】 to take effect

  2. Determine if device supports 【External Device Mode】

public boolean isSupportAuxMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operation device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.isAuxEnable();
}

  1. Determine if device is in 【External Device Mode】

public boolean isDeviceInAuxMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operation device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.getCurFunction() == AttrAndFunCode.SYS_INFO_FUNCTION_AUX;
}

7.1. Get External Device Play Status

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_AUX – AUX function
mask : 0x01 – Play status

Command construction

CommandBase getAuxPlayStatueCmd = CommandBuilder.buildGetAuxPlayStatueCmd();

Code example reference Query device system information

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {
    @Override
    public void onAuxStatusChange(BluetoothDevice device, boolean isPlay) {
        //Callback external device play status here
    }
});
//Execute get external device play status function and wait for result callback
controller.getAuxStatusInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be callback in BTRcspEventCallback#onAuxStatusChange
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

7.2. External Device Play or Pause

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_AUX – AUX function
type : AttrAndFunCode.FUNCTION_AUX_CMD_PAUSE_OR_PLAY – Play or pause
value : NULL

Command construction

CommandBase auxPlayOrPauseCmd = CommandBuilder.buildAuxPlayOrPauseCmd();

Code example reference Settings Function

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Execute external device play or pause function and wait for result callback
controller.auxPlayOrPause(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});
