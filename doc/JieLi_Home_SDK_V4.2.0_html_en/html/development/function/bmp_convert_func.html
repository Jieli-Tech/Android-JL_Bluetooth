21. Image Conversion

Converting regular PNG images (RGB, ARGB) to Jieli encoded files

String inPath = "Input file path (e.g.: /in.png, /in.jpg)";
String outPath = "Output file path (e.g.: out.res, out)";
//1. Initialize image conversion object
BmpConvert bmpConvert = new BmpConvert();
//2. Start image conversion
int flag = BmpConvert.TYPE_701N_RGB;         //701N image conversion algorithm - RGB
//flag = BmpConvert.TYPE_695N_RBG;           //695N image conversion algorithm - RGB
//V1.1.0+ supported
//flag = BmpConvert.TYPE_701N_ARGB;          //701N image conversion algorithm - ARGB
//V1.2.0+ supported
//flag = BmpConvert.TYPE_701N_RGB_NO_PACK;   //701N image conversion algorithm - RGB & no packaging
//flag = BmpConvert.TYPE_701N_ARGB_NO_PACK;  //701N image conversion algorithm - ARGB & no packaging
//V1.4.0+ supported
//flag = BmpConvert.TYPE_707N_RGB;           //707N image conversion algorithm - RGB
//flag = BmpConvert.TYPE_707N_ARGB;          //707N image conversion algorithm - ARGB
//flag = BmpConvert.TYPE_707N_RGB_NO_PACK;   //707N image conversion algorithm - RGB & no packaging
//flag = BmpConvert.TYPE_707N_ARGB_NO_PACK;  //707N image conversion algorithm - ARGB & no packaging

Important

  1. Image conversion function requires importing library: BmpConvert_Vxxx-release.aar

  2. Input image dimensions cannot exceed device screen dimensions

  3. Input image size should be as small as possible

  4. Select appropriate algorithm based on firmware SDK

21.1. ConvertResult

Image conversion result

public class ConvertResult implements Parcelable {
    /**
     * Result code
     * <p>
     * Description:<br/>
     * 1. Less than or equal to 0, considered as transcoding failure, negative numbers are error codes<br/>
     * 2. Greater than 0, means transcoding success
     * </p>
     */
    private int result;
    /**
     * Algorithm type
     */
    private int algorithm;
    /**
     * Data size
     */
    private int bufSize;
    /**
     * Pixel format
     * <p>
     * Description: Added from 707N algorithm, used for processing 【non-packaging algorithms】
     * </p>
     */
    private int pixelFormat;
    /**
     * Compression mode
     * <p>
     * Description: Added from 707N algorithm, used for processing 【non-packaging algorithms】
     * </p>
     */
    private int compressMode;
}

21.2. OnConvertListener

Conversion listener

public interface OnConvertListener {

    /**
     * Callback when conversion starts
     *
     * @param inFilePath String file path
     */
    void onStart(String inFilePath);

    /**
     * Callback when conversion ends
     *
     * @param isOk        boolean conversion result
     * @param outFilePath String output path
     */
    @Deprecated
    void onStop(boolean isOk, String outFilePath);

    /**
     * Callback when conversion ends
     *
     * @param result      ConvertResult conversion result
     * @param outFilePath String output file path
     */
    void onStop(ConvertResult result, String outFilePath);
}

21.4. Algorithm Selection Rules

  1. First, select according to 【chip type】

  2. Then, select according to 【whether packaging】

  3. Finally, select according to 【resource format】

For example: JL701N series chip, color screen warehouse SDK, push a.png image, packaging format

1. JL701N series chip
Can filter: TYPE_701N_RGB, TYPE_701N_ARGB, TYPE_701N_RGB_NO_PACK, TYPE_701N_ARGB_NO_PACK
2. Packaging format
Can filter: TYPE_701N_RGB, TYPE_701N_ARGB
3. a.png image
Since PNG images have alpha values, select TYPE_701N_ARGB
Of course, if you want smaller resources, you can choose TYPE_701N_RGB
