5. Equalizer Control Function

5.1. Get Equalizer Parameters

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attributes
mask : 0x01 << AttrAndFunCode.SYS_INFO_ATTR_EQ_PRESET_VALUE or 0x01 << AttrAndFunCode.SYS_INFO_ATTR_EQ – EQ preset values and EQ information

Command construction

CommandBase getEqInfoCmd = CommandBuilder.buildGetEqPresetAndEqValueCmd();

Code example reference Query device system information

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {

    @Override
    public void onEqPresetChange(BluetoothDevice device, EqPresetInfo eqPresetInfo) {
        //This will callback equalizer preset values
    }

    @Override
    public void onEqChange(BluetoothDevice device, EqInfo eqInfo) {
        //This will callback equalizer effect information
    }
});
//Execute get equalizer information function and wait for result callback
controller.getEqInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be callback in BTRcspEventCallback#onEqPresetChange、BTRcspEventCallback#onEqChange
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

5.2. Configure Equalizer Parameters

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attributes
type : AttrAndFunCode.SYS_INFO_ATTR_EQ – Identify equalizer parameters
value : Parameters

Whether dynamic

Parameter format

Notes

false

eqMode(1Byte) + eqValue(10 bytes)

eqMode highest bit is 0, indicates default parameters

true

eqMode(1Byte) + length(1Byte) + eqValue(n Bytes)

eqMode highest bit is 1, indicates dynamic adjustment, recommended

Command construction

boolean isDynamic = true; //Whether supports dynamic change
int eqMode = 6;  //EQ mode -- Custom
byte[] gains = new byte[10]; //EQ gain array - determined by dynamic segments
CommandBase setEqInfoCmd = CommandBuilder.buildSetEqValueCmd(isDynamic, (byte) eqMode, gains)();

Code example reference Configure device system properties

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {

    @Override
    public void onEqChange(BluetoothDevice device, EqInfo eqInfo) {
        //This will callback equalizer effect information
    }
});
EqInfo eqInfo = null; //EQ information, cannot be null
//Execute configure equalizer effect function and wait for result callback
controller.configEqInfo(controller.getUsingDevice(), eqInfo, new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

Note

  1. EqInfo

5.2.1. EqInfo

Equalizer information

public class EqInfo {

    /**
     * EQ mode
     */
    private int mode;
    /**
     * Gain value array
     */
    private byte[] value = new byte[10];
    /**
     * Preset value array
     */
    private int[] freqs = BluetoothConstant.DEFAULT_EQ_FREQS;
    /**
     * Whether dynamic EQ
     */
    private boolean dynamic;
    /**
     * Preset value array length
     */
    private int count = 10;
}

5.4. Set Extended Parameters

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attributes
type : AttrAndFunCode.SYS_INFO_ATTR_FIXED_LEN_DATA_FUN – Identify extended parameters
value : mask(4Bytes) + data(n Bytes)

Command construction

int mask = 0x03; //Extended mask  - Bit0 -- Reverberation   Bit1 -- Dynamic Limiter
byte[] data = new byte[0]; //Parameters, format： LTV format, composed of multiple LTV data
CommandBase setFixedLenDataCmd = CommandBuilder.buildSetFixedLenDataCmd(mask, data);

Code example reference Configure device system properties

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//mask - Function mask
//data - Parameter data
//Execute set additional function information function and wait for result callback
controller.setExpandDataInfo(controller.getUsingDevice(), mask, data, new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

Warning

1. Data consists of multiple LTV Format data
2. mask is 32Bit value, reverberation function is Bit0, dynamic limiter function is Bit1
3. Need to determine if device supports this function
