22. GIF Conversion

Used to encode GIF files into JieLi encoded files

//Get Gif transcoding object
GifConverter converter = GifConverter.getInstance();
//inputPath : Input file path (GIF file)
String inputPath = "Input file path(GIF file)";
//outputPath : Output file path (BIN file)
String outputPath = "Output file path(BIN file)";
//mode: Encoding mode
int mode = GifConverter.MODE_LOW_COMPRESSION_RATE; //Suggested low compression rate
// - GifConverter.MODE_LOW_COMPRESSION_RATE: Low compression rate
// - GifConverter.MODE_MEDIUM_COMPRESSION_RATE：Medium compression rate
// - GifConverter.MODE_HIGH_COMPRESSION_RATE ： High compression rate
//V1.2.0+ Added, default value: GifConverter.CHIP_701N
int chip = GifConverter.CHIP_707N; //Choose algorithm based on firmware chip
// - GifConverter.CHIP_701N : JL701N series chip
// - GifConverter.CHIP_707N : JL707N series chip
//V1.3.0+ Added, default value: true
boolean isPacketJLUI = true; //Whether to pack into JL UI format; false, for raw data
//Execute GIF transcoding function
converter.gif2BinAsync(inputPath, outputPath, mode, chip, isPacketJLUI, new GifConverter.ResultCallback<GifBin>() {
    @Override
    public void onSuccess(GifBin gifBin) {
        //Transcoding success
        //gifBin --- GIF information
    }

    @Override
    public void onError(int code, String message) {
        //Transcoding failure
        //code --- Error code
        //message --- Description information
        }
});

Important

  1. Image conversion function needs to import library: GifConvert_Vxxx-release.aar

  2. Input image size cannot exceed device screen size

  3. Input image size should be as small as possible

22.2. ResultCallback

Result callback

public interface ResultCallback<T> {

    /**
     * Callback success result
     *
     * @param result Result
     */
    void onSuccess(T result);

    /**
     * Callback failure event
     *
     * @param code    Error code
     * @param message Error description
     */
    void onError(int code, String message);
}
