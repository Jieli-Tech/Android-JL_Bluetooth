9. Light Control Function

Important

  1. Interface requires device to be in 【Light Mode】 to take effect

  2. Determine if device supports 【Light Mode】

public boolean isSupportLightMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operation device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.isLightEnable();
}

  1. Determine if device is in 【Light Mode】

public boolean isDeviceInLightMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operation device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.getCurFunction() == AttrAndFunCode.SYS_INFO_FUNCTION_LIGHT;
}

9.1. Get Light Control Information

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attributes
mask : 0x01 << AttrAndFunCode.SYS_INFO_ATTR_LIGHT – Light control

Command construction

CommandBase getLightControlInfoCmd = CommandBuilder.buildGetLightControlInfoCmd();

Code example reference Query device system information

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {
    @Override
    public void onLightControlInfo(BluetoothDevice device, LightControlInfo lightControlInfo) {
        //Callback light control information here
    }
});
//Execute get light control information function and wait for result callback
controller.getLightControlInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be callback in BTRcspEventCallback#onLightControlInfo
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

9.2. Set Light Control

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_PUBLIC – Public attributes
type : AttrAndFunCode.SYS_INFO_ATTR_LIGHT – Light control
value : data(n Bytes) – Control data

Command construction

LightControlInfo lightControlInfo;
CommandBase setLightControlInfoCmd = CommandBuilder.buildSetLightControlInfoCmd(lightControlInfo.toByteArray());

Code example reference Configure device system properties

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Execute set light control function and wait for result callback
controller.setLightControlInfo(controller.getUsingDevice(), lightControlInfo, new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});
