4. Device Music Control Function

Important

  1. Interface requires device to be in 【Music Mode】 to take effect

  2. Determine if device supports 【Music Mode】

public boolean isSupportDeviceMusicMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operating device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.isDevMusicEnable();
}

  1. Determine if device is in 【Music Mode】

public boolean isDeviceInDeviceMusicMode() {
    //Get RCSPController object
    RCSPController controller = RCSPController.getInstance();
    //Get current operating device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return false;
    DeviceInfo deviceInfo = controller.getDeviceInfo(usingDevice);
    if (null == deviceInfo) return false; //Device not initialized
    return deviceInfo.getCurFunction() == AttrAndFunCode.SYS_INFO_FUNCTION_MUSIC;
}

4.1. Get Device Music Information

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_MUSIC – Device music mode
mask : – Identify function code

Mask bit

Description

Bit0

Music playback status

Bit1

Music name information

Bit2

EQ information

Bit3

File type

Bit4

Playback mode

Command construction

CommandBase getMusicInfoCmd = CommandBuilder.buildGetMusicSysInfoCmd(0x07);

Code example reference Query device system information

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
//Add Bluetooth RCSP event listener
controller.addBTRcspEventCallback(new BTRcspEventCallback() {

    @Override
    public void onMusicNameChange(BluetoothDevice device, MusicNameInfo nameInfo) {
        //This will callback music name information
    }

    @Override
    public void onMusicStatusChange(BluetoothDevice device, MusicStatusInfo statusInfo) {
        //This will callback music playback status
    }

    @Override
    public void onPlayModeChange(BluetoothDevice device, PlayModeInfo playModeInfo) {
        //This will callback playback mode information
    }
});
//Execute get device music information function and wait for result callback
controller.getDeviceMusicInfo(controller.getUsingDevice(), new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
        //Result will be callback in BTRcspEventCallback#onMusicNameChange、
        // BTRcspEventCallback#onMusicStatusChange、BTRcspEventCallback#onPlayModeChange
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});

Note

  1. MusicNameInfo

  2. MusicStatusInfo

  3. PlayModeInfo

public class MusicNameInfo {

4.8. Jump to Specified Time

  1. JL_BluetoothManager Way

function : AttrAndFunCode.SYS_INFO_FUNCTION_MUSIC – Music mode
flag : AttrAndFunCode.FUNCTION_MUSIC_CMD_FAST_FORWARD or FUNCTION_MUSIC_CMD_RETREAT_QUICKLY
extend : Specified time (2 Bytes)

Command construction

int orientation = Constants.SEEK_ORIENTATION_BACK;//Jump direction
short time = 1234; //Jump timestamp
CommandBase command = orientation == Constants.SEEK_ORIENTATION_BACK ?
   CommandBuilder.buildFastForwardCmd(time) : CommandBuilder.buildRetreatQuicklyCmd(time);

Code example reference Settings Function

  1. RCSPController Way

//Get RCSPController object
RCSPController controller = RCSPController.getInstance();
int orientation = Constants.SEEK_ORIENTATION_FORWARD;
//orientation ： Constants.SEEK_ORIENTATION_FORWARD - forward，Constants.SEEK_ORIENTATION_BACK - backward
short time = 3000;
//time ： timestamp
//Execute jump to specified timestamp function and wait for result callback
controller.musicSeekToProgress(controller.getUsingDevice(), orientation, time, new OnRcspActionCallback<Boolean>() {
    @Override
    public void onSuccess(BluetoothDevice device, Boolean message) {
        //Success callback
    }

    @Override
    public void onError(BluetoothDevice device, BaseError error) {
        //Failure callback
        //error - error information
    }
});
