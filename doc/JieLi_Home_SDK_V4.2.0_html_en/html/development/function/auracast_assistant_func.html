24. Auracast Assistant

Function implementation class name: AuracastAssistant

24.1. Initialization

Initialize AuracastAssistant object

public void init() {
    //Get RCSPController object
    final RCSPController controller = RCSPController.getInstance();
    //Get current operating device
    BluetoothDevice usingDevice = controller.getUsingDevice();
    if (null == usingDevice) return;
    //Context
    Context context = MainApplication.getApplication();
    //Initialize AuracastAssistant object
    auracastAssistant = new AuracastAssistant(context, controller.getRcspOp(), usingDevice);
    //Whether device supports Auracast function
    auracastAssistant.isSupportAuracast();
}

Note

  1. Users can bind AuracastAssistant by specifying operation device object

  2. If user passes device field as null, SDK will default to using RcspOpImpl#getConnectedDevice()

  3. If AuracastAssistant#getDevice() is null, function cannot be used normally

  4. If device does not support Auracast function, AuracastAssistant functions cannot be used

24.2. Destroy Object

Destroy AuracastAssistant object, release resources

public void destroy() {
    if(null == auracastAssistant) return;
    //Destroy object
    auracastAssistant.destroy();
}

Important

  1. After AuracastAssistant object is destroyed, set object to null to avoid business processes still calling its function interfaces after destruction

  2. When device disconnects, AuracastAssistant needs to be destroyed

24.3.6. Start Searching Auracast Broadcast

public void startScanAuracastBroadcast() {
    if (!isSupportAuracastReceiver()) return; //Does not support Auracast receiver function
    if (isScanningAuracastBroadcast()) return; //Currently searching
    final AuracastReceiverCallback receiverCallback = new AuracastReceiverCallback() {
        @Override
        public void onSearchStarted(int reason) {
            //Callback for search start
            //reason --- reason
            //  - Constants.REASON_BY_SDK       --- SDK triggered
            //  - Constants.REASON_BY_DEVICE    --- Device triggered
        }

        @Override
        public void onSearchStopped(int reason) {
            //Callback for search end
            //reason --- reason
            //  - Constants.REASON_BY_SDK       --- SDK triggered
            //  - Constants.REASON_BY_DEVICE    --- Device triggered

            //Get all discovered broadcasts
            List<AuracastBroadcast> broadcasts = auracastAssistant.getDiscoveredBroadcast();
            //Remove receiver event listener
            auracastAssistant.removeAuracastReceiverCallback(this);
        }

        @Override
        public void onBroadcastFound(@NonNull AuracastBroadcast broadcast) {
            //Callback for discovered Auracast broadcast information
        }
    };
    //Register receiver event listener
    auracastAssistant.addAuracastReceiverCallback(receiverCallback);
    //Search configuration information
    //timeout -- timeout, unit is milliseconds, default is 48 seconds
    //isFilterBroadcast -- whether to filter duplicate broadcast information, default is true
    ScanOption option = new ScanOption();
    //Execute search Auracast broadcast
    auracastAssistant.startScan(option, new OnRcspActionCallback<Integer>() {
        @Override
        public void onSuccess(BluetoothDevice device, Integer message) {
            //Callback for operation success
            // message --- operation result
            // - ScanResponse.RESULT_SUCCESS --- operation success/not in search state
            // - ScanResponse.RESULT_SCANNING --- currently searching, do not repeat operation
            // - ScanResponse#RESULT_LISTENING_BROADCAST_BAN_SCAN --- scanning not allowed during listening broadcast process
            // - ScanResponse#RESULT_DEVICE_BUSY --- device busy
            //Search status and search device results will be returned in AuracastReceiverCallback#onSearchStarted,
            // AuracastReceiverCallback#onBroadcastFound and AuracastReceiverCallback#onSearchStopped
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Callback for operation failure
            //error --- error information
            auracastAssistant.removeAuracastReceiverCallback(receiverCallback);
        }
    });
}

24.3.7. Stop Searching Auracast Broadcast

public void stopScanAuracastBroadcast() {
    if (!isSupportAuracastReceiver()) return; //Does not support Auracast receiver function
    if (!isScanningAuracastBroadcast()) return; //Not in search state
    final AuracastReceiverCallback receiverCallback = new AuracastReceiverCallback() {
        @Override
        public void onSearchStopped(int reason) {
            //Callback for search end
            //reason --- reason
            //  - Constants.REASON_BY_SDK       --- SDK triggered
            //  - Constants.REASON_BY_DEVICE    --- Device triggered
            auracastAssistant.removeAuracastReceiverCallback(this);
        }
    };
    //Register receiver event listener
    auracastAssistant.addAuracastReceiverCallback(receiverCallback);
    //Execute stop search Auracast broadcast
    auracastAssistant.stopScan(new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Callback for operation success
            //Search status will be returned in AuracastReceiverCallback#onSearchStopped
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Callback for operation failure
            //error --- error information
            auracastAssistant.removeAuracastReceiverCallback(receiverCallback);
        }
    });
}

24.3.9. Add Auracast Broadcast Audio Source

public void addSource() {
    if (!isSupportAuracastReceiver()) return; //Does not support Auracast receiver function
    stopScanAuracastBroadcast(); //Recommend stopping broadcast search first
    final AuracastBroadcast addBroadcast = new AuracastBroadcast(); //Selected broadcast information
    if (addBroadcast.isEncrypted()) { //If broadcast is encrypted, need to add broadcast key
        addBroadcast.setBroadcastCode(new byte[16]);
    }
    final AuracastReceiverCallback receiverCallback = new AuracastReceiverCallback() {
        @Override
        public void onBroadcastState(@NonNull BluetoothDevice device, @NonNull AuracastBroadcast broadcast) {
            //Callback for broadcast status change
            if (addBroadcast.equals(broadcast)) {
                if (broadcast.getSyncState() != StateCode.STATE_SYNCING) {
                    auracastAssistant.removeAuracastReceiverCallback(this);
                }
            }
        }
    };
    //Register receiver event listener
    auracastAssistant.addAuracastReceiverCallback(receiverCallback);
    //Execute add audio function
    auracastAssistant.addSource(addBroadcast, new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Callback for operation success
            //Audio broadcast synchronization status will be callback in AuracastReceiverCallback#onBroadcastState
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Callback for operation failure
            //error --- error information
            auracastAssistant.removeAuracastReceiverCallback(receiverCallback);
        }
    });
}

Note

  1. Before adding Auracast broadcast audio source, recommend stopping broadcast search function

  2. If Auracast broadcast is encrypted broadcast, need to configure broadcast key field, length must not exceed 16 bytes, excess part will be truncated by SDK

24.3.10. Remove Auracast Broadcast Audio Source

public void removeSource() {
    if (!isSupportAuracastReceiver()) return; //Does not support Auracast receiver function
    final AuracastBroadcast broadcast = getListeningBroadcast(); //Get currently listening broadcast information
    if (null == broadcast) return; //Not in listening music state
    final AuracastReceiverCallback receiverCallback = new AuracastReceiverCallback() {
        @Override
        public void onBroadcastState(@NonNull BluetoothDevice device, @NonNull AuracastBroadcast broadcast) {
            //Callback for broadcast status change
            if (broadcast.getSyncState() != StateCode.STATE_SYNCING) {
                auracastAssistant.removeAuracastReceiverCallback(this);
            }
        }
    };
    //Register receiver event listener
    auracastAssistant.addAuracastReceiverCallback(receiverCallback);
    //Execute remove audio function
    auracastAssistant.removeSource(new OnRcspActionCallback<Boolean>() {
        @Override
        public void onSuccess(BluetoothDevice device, Boolean message) {
            //Callback for operation success
            //Audio broadcast synchronization status will be callback in AuracastReceiverCallback#onBroadcastState
        }

        @Override
        public void onError(BluetoothDevice device, BaseError error) {
            //Callback for operation failure
            //error --- error information
            auracastAssistant.removeAuracastReceiverCallback(receiverCallback);
        }
    });
}

Note

  1. Before removing Auracast broadcast audio source, ensure device is currently in listening Auracast broadcast state, otherwise function is invalid
